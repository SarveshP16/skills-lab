DevOps: from commit to production.

Package apps in containers, build pipelines that test, scan and ship them, describe whole environments as code, run them on Kubernetes, and know when something breaks before your users do.

This is the plan for the track. The labs will run in the same simulated terminal as the Linux and Git tracks, with an editor panel for Dockerfiles, YAML and Terraform.

The DevOps loop

Every change goes round this loop. Each module of the track covers part of it.

Security at every step. Scanning images, gating pipelines, checking infrastructure code, locking down pods and watching for attacks are part of each module, not an add-on at the end. That's what makes it DevSecOps.

Modules

Each module ends with a capstone (★): a bigger ticket with no hints.

Tools you'll use

All simulated in your browser. Nothing to install, nothing to pay for.

How the labs will work

A real terminal

Type docker, kubectl, terraform, ansible, helm and aws commands on simulated machines. Tasks tick as you go.

An editor panel

Write Dockerfiles, GitHub Actions workflows, Bamboo Specs, Terraform and Kubernetes YAML, then run them and read the result.

Safe to break

Bad deploys, failed pipelines and outages only hit Kestrel's simulated systems, so you can practise rollbacks and incident response for real.
