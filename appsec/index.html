AppSec: break it, then fix it.

Kestrel Shop is a web app full of security holes. Find them the way an attacker would, exploit them safely, then fix the code and prove the fix holds. By the end you'll review code, run scanners in the pipeline and write findings like an AppSec engineer.

This is the plan for the track. It goes much deeper than the secure-coding labs in the Python track: a whole app to attack instead of one bug per lab.

How every lab goes

Each vulnerability is worked from both sides: attacker first, then defender.

Only attack what you're allowed to. Every attack in this track hits Kestrel's own simulated app. Trying these techniques on real sites without written permission is illegal, and SEC-506 covers how real testers get that permission and report what they find.

Modules

Tools you'll use

All simulated in your browser. Nothing to install, nothing to pay for.

How the labs will work

A request tool

Capture a request, change it, replay it, and see what the server does. curl works in the terminal too.

Real code to fix

Kestrel Shop's backend is Python, so you can read it and fix it in the editor. Frontend bugs like XSS are in JavaScript.

Proof, not promises

A fix only counts when the exploit stops working and a regression test keeps it from coming back.
